# NexSpace 🚀

NexSpace is a modern, mobile-first platform connecting Developers and Clients. Developers can showcase their projects, gain upvotes and signals, and track other creators. Clients can post problem requests and connect with developers who have the right skills.

## Features ✨
- **100% Passwordless Authentication:** Seamless, secure, and modern 8-digit OTP signups and logins via email.
- **Dual-Role Ecosystem:** Sign up as a Developer to showcase your work, or as a Client to post requests.
- **Project Showcases & Problem Boards:** Dedicated feeds for discovering new projects and viewing active client requests.
- **Social Signals:** Upvote projects, track your favorite developers, and build your reputation.
- **Mobile-First Design:** Fully responsive UI with bottom-navigation on mobile devices, ensuring a perfect experience on all screen sizes.

## Tech Stack 🛠️
- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Backend & Auth:** [Supabase](https://supabase.com/)
- **Icons:** [Lucide React](https://lucide.dev/)

## Getting Started 💻

First, clone the repository and install the dependencies:

```bash
npm install
```

Set up your `.env.local` file with your Supabase credentials:

```env
NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
